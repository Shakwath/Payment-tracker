#Payment_Tracker

A modern Payment Tracking System built with React + Vite to manage student payments, payment history, dues, and progress efficiently.

Features

- Student/Guardian Dashboard
- Online & Offline Payment Tracking
- Payment Progress & History
- Transaction Management
- Admin Dashboard
- Payment & Due Overview

🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- DaisyUI
- React Router
- JavaScript

🚧 Currently under development.

More features and improvements will be added soon.
